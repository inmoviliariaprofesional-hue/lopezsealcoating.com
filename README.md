# Lopez Sealcoating LLC — Presencia Digital

Repositorio del proyecto de presencia digital de **Lopez Sealcoating LLC** (Chicagoland, Illinois), desarrollado por **Aimarktech**.

## Contenido

- `propuesta/` — Propuesta comercial para el cliente (Demetrio López) y su generador.
- *(próximamente)* `web/` — Sitio web bilingüe (EN/ES) de conversión.

## Cliente

- **Negocio:** Lopez Sealcoating LLC
- **Servicios:** Sealcoating (sellado de asfalto) y pintura de líneas / cajones de estacionamiento / cebras peatonales.
- **Zona:** Chicagoland, radio 30–40 millas. Temporada: mayo–octubre.
- **Público:** Bilingüe (inglés/español), residencial y comercial.
